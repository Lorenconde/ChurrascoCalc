# 🔥 ChurrascoCalc 

Aplicação web inteligente para planejamento de churrascos.

Calcula automaticamente:
- quantidade de carnes
- bebidas
- carvão
- refrigerante

com base no número de participantes e tipos de carne selecionados.

---

## 🚀 Tecnologias

HTML5  
CSS3  
JavaScript  
LocalStorage API  

---

## 📊 Funcionalidades

✔ cálculo automático  
✔ seleção de carnes  
✔ lista dinâmica  
✔ salvar cálculo  
✔ layout moderno
